Honeypots

Three specialized honeypots.

Each honeypot captures a distinct attack vector and feeds the correlation pipeline automatically.

SSH :2222 · Telnet :2223
SSH / Telnet Honeypot
Medium-interaction honeypot. Captures interactive sessions, executed commands and files downloaded by attackers. Customized as a fake MongoDB banking server.
SMB :445 · MySQL :3306
Multi-Protocol Honeypot
Captures malware, network exploits and in-memory binaries across 11 exposed services including SMB, MySQL, FTP, MongoDB and MSSQL.
HTTP :8080 · :8888
LLM HTTP Honeypot
LLM-powered HTTP honeypot. Generates realistic, context-aware responses via Mistral 7B to trap bots, web scanners and automated exploits.
Zeek — Passive Network Analyzer (not a honeypot)
Zeek passively monitors incoming traffic on eno8303 / eno12399 and enriches cross-honeypot correlation: SYN scans, NTLM sessions, suspicious DNS queries.
