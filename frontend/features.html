FUNCTIONAL OVERVIEW

Sept piliers forensiques

ForenHive combine 3 honeypots, 1 capteur NDR, un pipeline ETL, un moteur d'enrichissement, du mapping MITRE ATT&CK et une chaîne de custody RFC 3161 dans une seule plateforme.

Honeypots de capture

3 honeypots interopérables couvrant SSH, SMB et HTTP.

  • Cowrie · SSH/Telnet brute force + commandes shell
  • Dionaea · capture binaires malware (Mirai, etc.)
  • Galah · réponses HTTP générées par Mistral 7B

Capteur NDR passif

Zeek inspecte le trafic réseau pour corréler les sessions inter-honeypots et capturer ce que les honeypots manquent.

  • Zeek · IDS passif sur eno12399
  • conn.log · http.log · weird.log · notice.log
  • Corrélation cross-honeypot par IP/port

Pipeline ETL Temps Réel

Filebeat Logstash Elasticsearch normalisation ECS, enrichissement GeoIP, indices quotidiens.

  • 11.4M+ événements indexés (état actuel)
  • Précision milliseconde timezone Africa/Tunis
  • Filtres par honeypot tags ECS

Threat Intelligence Multi-Source

Enrichissement automatique de chaque IP attaquante via 4 sources externes.

  • AbuseIPDB score réputation
  • MaxMind GeoLite2-ASN géolocalisation
  • IPLocate détection Tor / VPN / Proxy
  • WHOIS CIDR + ASN organisation

MITRE ATT&CK + Kill Chain

Mapping automatique des techniques observées et reconstruction de la kill chain Lockheed Martin.

  • Détection T1110, T1078, T1059, T1190, T1210…
  • Phase de la kill chain par session (1 8)
  • Score de risque pondéré 0–100

Analyse Binaire Offline

Tous les binaires capturés par Dionaea sont scannés localement.

  • YARA règles Mirai, ransomware, cryptominer
  • VirusTotal SHA-256 lookup (cache 24 h)
  • Profilage suspect via Ollama Mistral 7B

Chaîne de Custody RFC 3161

Chaque session est scellée cryptographiquement et horodatée par une TSA publique.

  • SHA-256 par enregistrement
  • Hash chain (chaque record lié au précédent)
  • Merkle root + RFC 3161 batch signature
  • Rapports PDF certifiés exportables
