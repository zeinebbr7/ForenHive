2.2 Analysis Pipeline

Pipeline: Honeypot Logs → Filebeat → Logstash → Elasticsearch → ForenHive Forensic Engine (engine.py) → IOC Extraction, YARA Scan, VT Lookup, MITRE Mapping (hybrid: deterministic + Mistral 7B narrative), Risk Scoring, Suspect Profiling, Timeline Construction → Report Generation (WeasyPrint).

The MITRE ATT&CK mapping uses a hybrid approach: 15 deterministic rules map observed commands to technique IDs, supplemented by an LLM-generated narrative (Mistral 7B, temperature 0.3, max 80 tokens) that contextualizes the attack chain without introducing unverified technique IDs.3

2.3 Risk Scoring Model (6 Signals)

The composite risk score is computed from 6 deterministic signals, each contributing a defined maximum point value. The final score is capped at 100 and aggregates data across all honeypots hit by the same source IP within a 24-hour window.

SignalMax PtsDescription
IP Reputation25AbuseIPDB abuse confidence score (thresholded). Skipped for private IPs.
Compromise Confirmed25Binary: successful authentication or exploit activation on any honeypot.
Brute Force / Automation20Aggregate login attempt volume and velocity. Bonus for targeted wordlists.
Malware Detected15YARA severity (CRITICAL/HIGH/match) and VirusTotal detection count.
Anonymization / Evasion10Tor/VPN/proxy usage + critical port targeting (conditional).
Attack Sophistication5Kill chain depth (0-8 stages) + multi-honeypot coordination bonus.
